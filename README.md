# Urbanización Alirio Rojas

Landing page estática para presentar el proyecto de vivienda de Acacías, Meta.

## Vista local

Desde esta carpeta, ejecuta:

```powershell
python -m http.server 4173
```

Luego abre <http://localhost:4173>.

## Antes de publicar

- Confirma el teléfono de WhatsApp, dirección, distancia a la avenida, características, subsidios y condiciones comerciales con la empresa.
- Confirma con la empresa que los renders y el plano promocional siguen vigentes y que la empresa autoriza su publicación.
- Confirma la razón social que debe figurar como responsable comercial.
- Los renders y el plano están guardados localmente en `assets/`; consulta `assets/SOURCES.md` para su procedencia.
- Las tipografías cargan desde Google Fonts.

La página no recopila datos ni usa servidor de aplicaciones. Los botones de contacto abren WhatsApp o el marcador telefónico.
